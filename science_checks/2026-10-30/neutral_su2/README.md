# SU(2) neutral-gauge checks

These JSON outputs reproduce the finite, neutral SU(2) results included with the 30 October 2026 QICT scientific package. They do not represent charged C8/C10 or full electroweak amplitudes. The R3 matrix itself has not been uploaded with this commit; the full numerical test depends on that matrix and the recoupling code.

The five original spin-network source modules are already stored in GitHub at
`snapshot-2026-10-17/task_evidence/TASK3_FRONTIER/TASK3_BLOCKSPARSE_DEP/stage_b/code/`.
Their content blob hashes agree with the reviewed local source modules, so those modules have **not** been copied again.

A successful comparison of two finite Galerkin projections is not a convergence theorem for the full physical transfer. The charged h8/h9/h10 promotion gate remains open.
