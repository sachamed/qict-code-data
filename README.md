# QICT Code and Data Release

This public repository is the reproducibility archive accompanying:

**Quantum Copy-Time Geometry: Standard-Model Gauge Algebra, Family Structure, and a Parameter-Free BCC Photon Signature**

Author: **Mohamed Sacha** — Independent Researcher, Morocco.

The release contains the complete computational package prepared for the submission: source code, numerical input data, derived results, validation records, reproducibility scripts, and SHA-256 manifests.

## Expected structure

- `code/` — computational and validation source code
- `data/` — numerical and primary input data
- `results/` — generated numerical results and certificates
- `validation/` — publication and consistency audits
- `REPRODUCE_ALL.py` — top-level reproduction entry point
- `MANIFEST_SHA256.txt` and `GITHUB_EXPORT_SHA256.txt` — integrity manifests
